# 动效

出处：`ui/components/BounceOverscroll.kt`、`ui/theme/Theme.kt`、`ui/Dest.kt`（按压）、`ui/player/LyricsScreen.kt`、`ui/settings/SettingsScreen.kt`。

## 总则

- 动效走 MD3E 的 `MaterialTheme.motionScheme`：默认 expressive；系统 / 设置里的「减少动效」开启时切 standard。位移 / 缩放走 spatial spec、透明度 / 颜色走 effects spec，不手写 tween 时长（个别注明出处者除外）。
- 按压反馈见《组件》的 pressScale / pressRebound。

## 回弹过冲（BounceOverscrollEffect）

自研 iOS 式回弹（平台默认的拉伸 / 发光不用），**全局唯一一套参数、所有列表与页面共用，不做页面级变体**：

| 参数 | 值 | 说明 |
|---|---|---|
| 最大拖出量 `BOUNCE_MAX_DISTANCE_DP` | **24dp**（2026-11-27 用户定，原 96dp） | 阻尼变换的渐近值：拖动量经 `max·(1 − 1/(1 + raw/max))` 变换，越拉越接近 24dp 但不到 |
| 回程弹簧阻尼 `BOUNCE_SPRING_DAMPING` | 1.0（临界阻尼 DampingRatioNoBouncy） | 回程单调收敛、不过 0 点 |
| 回程弹簧刚度 `BOUNCE_SPRING_STIFFNESS` | StiffnessMediumLow（400） | 回程约 0.2–0.3s 落定 |

为什么必须是临界阻尼：欠阻尼（旧值 0.5）回弹到位后会绕 0 点衰减振荡数个像素，表现为「滑到最下面有一记细微弹跳」（底部 fling 位移最大、最明显）。有防回归单测钉住阻尼 ≥ 1.0 与最大拖出量 24dp，不许顺手改。

机制要点：

- 手势结束（applyToFling）才启动弹簧回程；回程被新拖动打断时，先用逆变换把内部 rawOffset 对齐到当前视觉位移再续算，避免位置跳变。
- `applyTop` / `applyBottom` 只是「哪条边参与吸收」的功能开关，不是手感参数：主页顶边有下拉刷新，传 `applyTop = false`，底边照常回弹。
- 接入面：主页、资料库（含本地页）、详情页脚手架、歌词页、设置各级页——全部同一组件同一参数。

## 歌词动效

详见《歌词》，参数在此登记：

| 项 | 值 |
|---|---|
| 跟随滚动（当前行在视口内） | animateScrollBy 按像素差、450ms、CubicBezierEasing(0.2, 0, 0, 1)（MD3 emphasized 曲线） |
| 跟随滚动（当前行不在视口内） | animateScrollToItem 直接定位 |
| 当前行锚点 | 视口高度的 20% |
| 距离模糊过渡 | 300ms tween（焦点移动时平滑，不跳变） |
| 行缩放 | 当前行 1.0 / 非当前行 0.8，spatial spec，锚点左中 |
| 首行入场弹簧 | 切歌 / 首次播放时首行从锚点下 120dp、透明起步，spatial / effects spec 落定；弹簧期间行进度冻结、跟随暂停 |
| 切页入场 stagger | 入场窗口约 700ms；窗口期内组成的行按与当前行的距离逐行淡入 + 上移，每行延迟 40ms、最多 6 行；窗口后滚入的行直接最终态 |
| 逐字扫过 | 见《歌词》（双层 Brush 渐变、边界 2dp 渐隐） |

## 页面与容器动效

- 「我的」页板块首次入场：220ms 淡入 + 上浮 12dp，按组延迟 45ms 一档；只播一次（播过的组记在 sheet 作用域，重建不重播）。
- 「我的」页二级页切换：进页右滑入 / 返回左滑出 + 淡入淡出，走 motionScheme。
- 播放器封面 ↔ 歌词 ↔ 队列切换：封面退出淡出 + 缩到 0.94，歌词 / 队列淡入 + 从下方 1/12 处上移；不用共享元素过渡（曾是闪烁源，已删）。
- 播放 / 暂停图标切换（播放键与 MiniPlayer 同款）：淡入淡出 + 缩放 0.8 ↔ 1。
- MiniPlayer / 底栏显隐：纵向滑入滑出 + 淡入淡出（spatial / effects spec）。
- 标题头标题切换：淡入淡出 + 上下滑 1/4 高度。
- 歌名 / 歌手轮播：见《排版与字体》（60 / 30dp/s）。
