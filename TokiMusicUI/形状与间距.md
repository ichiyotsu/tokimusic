# 形状与间距

出处：`ui/theme/Theme.kt`、`ui/components/Common.kt`（segmentedCorners / 行组件）、`android/tokiui/tokens`（space token）、各页面源码。

## 圆角阶梯

主题直接用 MD3 默认 `Shapes()`，数值与 TokiUI 形状阶梯一致：

| 档 | 值 | 典型用法（代码实测） |
|---|---|---|
| extraSmall | 4dp | 分段圆角的小角（组内接缝） |
| small | 8dp | 详情页歌曲行的分段小角 |
| medium | 12dp | 小封面、次级容器 |
| large | 16dp | 封面（歌词视图小封面、本地页歌单封面位）、模式钮 |
| extraLarge | 28dp | 分组容器、面板顶角、设置卡 |
| 全圆（percent 50） | — | 胶囊、圆形钮、pill |

组件级的具体圆角（以代码为准）：

| 表面 | 圆角 |
|---|---|
| 歌单卡封面（140dp） | 20dp（与 28dp 源徽标 14dp 半径 + 6dp 边距同心：14 + 6 = 20） |
| 歌曲行封面（48dp） | 14dp |
| MiniPlayer 封面（50dp） | 14dp |
| 卡片行（TokiCardRow / 本地页选项卡） | 20dp |
| 详情页歌曲行（分段） | 大 20dp / 小 8dp |
| 设置分组卡、设置入口行、更多面板分组容器 | 28dp（分段小角 4dp） |
| 底部弹窗容器 TokiSheetContainer | 顶 32dp |
| 更多面板 / 我的页（ModalBottomSheet） | 顶 28dp |
| 统一弹窗 TokiDialog | 28dp |
| 播放器面板 | 顶 32dp（面板顶部距全屏顶 28dp） |
| 播放键 | 圆角随播放态动画：播放中 42dp、暂停 28dp |

## 分段圆角（segmentedCorners）

出处：`Common.kt` 的 `SegmentPosition` / `positionOf` / `segmentedCorners`。

一组相邻卡片按位置取形：首项只有顶部大圆角、末项只有底部大圆角、中间项全小角、单项全大圆角；接缝侧一律小角。两个参数档：

- 设置系（设置分组卡、入口行、悬浮歌词开关 / 控制卡）：大 28dp / 小 4dp；组内相邻卡间距 4dp，组与组之间 12dp。
- 详情页歌曲行：大 20dp / 小 8dp；行上下边距各 4dp（相邻行间距 8dp）。

新做分组列表时按这两档选，不要新造数值。

## 间距

- **页边距 24dp** 是全应用标准（内容横向 padding、标题头横向 padding 均是 24dp；与 TokiUI space token 的 xl 一致，标题头经 `tokiSpace("xl")` 取）。
- 例外：详情页（歌单 / 歌手 / 专辑）列表区页边 16dp；MiniPlayer 横向边距 16dp。
- space token 全表（运行时少量位置经 `tokiSpace` 读取，其余为字面 dp）：xs 4 / sm 8 / md 12 / lg 16 / xl 24 / xxl 32。
- 底栏区：导航胶囊与搜索圆钮间距 8dp；MiniPlayer 与底栏之间 8dp；底栏底边距 8dp（MiniPlayer 单独贴底时 16dp，与其横向边距对齐）。
- 分组标题（SectionTitle）：上 24dp、下 8dp，左右 24dp。
