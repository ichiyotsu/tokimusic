# 排版与字体

出处：`ui/theme/Theme.kt`、`ui/theme/AppTypeface.kt`、`ui/player/LyricsScreen.kt`。

## 字体文件（`res/font/`，随包提交）

| 文件 | 内容 | 形态 |
|---|---|---|
| `inter.ttf` | Inter（Google Fonts 版） | 可变字体，Normal / Medium / SemiBold / Bold 四档经 FontVariation 取 |
| `pingfang_bold.ttf` | 苹方 SC Bold | 静态 Bold（10,923,212 B） |
| `noto_sans_jp_bold.ttf` | Noto Sans JP Bold 全量 | 静态 Bold（5,558,848 B；15,369 码位：假名 / 半角片假名 / 一般汉字 / 兼容字全覆盖；usWeightClass 700、无 fvar） |
| `noto_sans_kr.ttf` | Noto Sans KR Bold | 静态 Bold（谚文兜底） |

CJK 文件一律用静态 Bold 而不是可变字体：Compose 的资源字体加载路径不传 variationSettings，可变 CJK 会按默认轴（Thin）出字。声明时只给 `FontWeight.Bold`、不传 variationSettings。

## 字重：全局 Bold

- **全应用所有文字样式都是 Bold**——`Typography()` 的全部样式（含 15 个 emphasized 变体）在主题里统一改成 Inter 字体族 + Bold（用户 2026-11-21 定）。
- 这是对 TokiUI「正文 Regular」的明确偏离，不要按 TokiUI 改回去。
- 字号阶梯用 MD3 默认 `Typography` 原值，主题不改字号。
- 主题在根部提供 `LocalContentColor = onBackground`（MaterialExpressiveTheme 不提供它，不设的话裸 `Text()` 在深色底上是黑字）。

## 字体族与回退链

- 默认族 `InterFamily`：Inter 四档 + CJK 静态 Bold（苹方 → JP → KR）。
- `CjkBoldFamily`：只有三个 CJK 静态 Bold，给 CJK 为主的标题用（如歌单卡片标题）——默认族里 Inter 条目排在 CJK 之前，Bold 请求会先命中 Inter、CJK 静态 Bold 选不中。
- 通用回退链顺序：**苹方 → Noto JP → Noto KR**（`cjkFallbackOrder`）。

## 日文字体规则（假名判定）

出处：`AppTypeface.kt` 的 `containsKana` / `fontFamilyForText` / `JpBoldFamily`（0.1.21 定，0.1.22 扩大接入面）。

- 判定：文本含任一假名即按日语文本处理。范围：平假名 U+3040–309F、片假名 U+30A0–30FF、片假名语音扩展 U+31F0–31FF、半角片假名 U+FF66–FF9D。
- 命中 → 整段用 `JpBoldFamily`（Noto JP → 苹方 → KR）：假名与汉字都取日文字形，不靠逐字回退碰运气。
- 未命中 → 用调用处原字体（纯汉字无法区分中日，按中文链走；不含假名的日文标题同理，属已知边界）。
- 接入面（渲染用户内容文本处统一经 `fontFamilyForText`）：歌曲行标题 / 副标题、歌单卡名、详情页大标题、歌手页大标题、专辑详情大标题、播放器与 MiniPlayer 的歌名 / 歌手名、队列行、歌词原词行（逐行判定；翻译行、罗马音行各自按自身文本判定）、更多面板头部、歌曲操作弹窗、本地页歌单行、歌单详情的创建者 / 简介。
- 例外：听歌统计的 Treemap 是 Canvas 自绘文本，没有字体族接入面，不走本规则。

## 常用文字角色

| 角色 | 样式 |
|---|---|
| 页面大标题（标题头） | headlineMedium Bold（全应用统一一个角色） |
| 分区分组标题（SectionTitle） | titleLarge Bold |
| 播放器歌名 | headlineSmall Bold |
| 播放器歌手名 | titleMedium Bold |
| 列表行标题 / 说明 | titleMedium / bodySmall（说明走 onSurfaceVariant） |
| 详情页大标题 | headlineMedium Bold、单行省略 |

歌名 / 歌手过长时走轮播（basicMarquee）：歌名 60dp/s、歌手 30dp/s，初次延迟 1s、每轮间隔 3s；不溢出则静止。歌名的边缘淡入淡出只在真正溢出时加。

## 歌词排版

详见《歌词》；排版要点：

- 原词行：28sp Bold、**左对齐**；当前行与非当前行同字号排版（行高恒定），非当前行的视觉缩小只靠 0.8 图形缩放，不改字号（改字号会让行距跳动）。
- 行序：原词 → 罗马音 → 翻译（罗马音夹在中间）；罗马音 / 翻译用 bodyLarge Bold、不参与逐字高亮、三行之间不另加间距。
- 透明度：原词行 当前 1.0 / 未播 0.85 / 已播 0.75；翻译与罗马音 当前用 dim 色 / 未播 0.4 / 已播 0.3。
