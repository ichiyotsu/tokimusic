# 组件

出处：`ui/components/` 各文件、`ui/player/PlayerScreen.kt`、`ui/settings/SettingsScreen.kt`。

## 统一标题头（OverlayTitleHeader）

全应用只有一个标题头：标题 chip（全圆、headlineMedium Bold）+ 返回 chip（56dp 圆、24dp 图标），两者同磨砂、恒显示（不随滚动出现 / 消失），返回与标题间距固定 12dp；横向边距 24dp、最小高 64dp（含状态栏 padding）。strong 形态与底栏同配方（32dp 模糊 + 45% veil）。标题切换走淡入 + 上滑过渡。

## 悬浮底栏

出处：`FloatingNavBar.kt`、`TokiMusicApp.kt` 的 BottomChrome / NavBarSlot。

- 结构：导航胶囊（主页 / 资料库 2 个 tab）+ 胶囊右侧 8dp 的独立搜索圆钮（56dp）；上方是 MiniPlayer，两者间距 8dp；整组悬浮居中、底边距 8dp。
- 胶囊：加强档玻璃（32dp + 45% veil），玻璃挂在 matchParentSize 兄弟层上，条目行是唯一决定尺寸的常规子元素（两个 matchParentSize 子元素会让胶囊塌成 0）。
- 导航项：纯图标无文字，64×56dp、图标 24dp、单套实心图标；选中态只靠 pill 底色表达（深 `#54545F` / 浅 `#D9D6E2`），图标色恒为 onSurface。长按出文字标签（TokiLongPressLabel）。
- 宽屏走侧边 rail，条目与窄屏共用同一份 `navEntries`，不漂移。

## MiniPlayer

出处：`PlayerScreen.kt` 的 `MiniPlayer`。

- 形态：全圆胶囊，横向边距 16dp；85dp 玻璃 + 动态 veil（见《玻璃与材质》《色彩》）。
- 内容：封面 50dp（圆角 14dp，向右偏移 4dp）+ 歌名（titleMedium）/ 歌手名（bodySmall，`#D9D9D9`）+ 播放 / 暂停钮（56dp 圆、图标 32dp，靠右且是控制区唯一按钮——**没有下一首按钮**）。
- 切歌：左右划（阈值 72dp，左划下一首、右划上一首）。
- 进度线：底部 2dp 细线，左右各内收 38dp（对齐封面竖直中线）；颜色取当前封面取色的文字色，轨道为同色 30%。

## 播放器更多面板（MoreSheet）

出处：`PlayerScreen.kt` 的 `MoreSheet`（0.1.22 定玻璃，0.2.0-beta1 定分组，0.1.23 改套设置页组件家族）。

- 底：容器透明、顶圆角 28dp；85dp 玻璃 + 主题色 veil（alpha 0.78）；自绘拖柄 32×4dp。内容列横向 24dp，与标题行同口径（见《形状与间距》的弹窗对齐口径）。
- 头部两行：封面 56dp（圆角 16dp）+ 歌名（titleMedium）；第二行 = 裸来源图标（16dp、无底色、tint 与文字同为 onSurfaceVariant）+「歌手 · 时长 · 发行日期」文本（bodySmall；时长 / 日期缺失时整段不显示，不编造）。
- 分组列表：**与「我的」页同一套组件**——每行一张 `TokiSettingsCard` 分段卡（First / Middle / Last，底色改为半透明 surfaceContainer 55% 压在玻璃上、横向边距 0），组内卡间距 4dp、组间 12dp；行规格与设置页行相同（64dp 高、24dp 图标、titleMedium；开关行行尾 Switch、整行可点切换）：
  - 操作组：投放、下一首播放。
  - 歌词设定组：翻译 / 罗马音 / 逐字高亮 / **歌词模糊**四个开关 + 逐字时序（行 + 滑杆 ±500ms、50ms 步进 + 说明，收在末段卡内）。与设置里的歌词开关同一批 store 值，改完立即生效；「歌词模糊」开关只在本面板有（见《歌词》）。
- 底栏：只留一个通栏 56dp 的喜欢 FilledTonalButton（星形图标，文案随状态为「喜欢 / 取消喜欢」）——0.1.23 起播放 / 暂停按钮已删（播放器主界面有控制）。每个动作在面板里只出现一次（喜欢只在底栏）；点按就地生效、不关面板。

## 歌曲操作弹窗（SongActionsSheet）

长按歌曲出：头部歌曲行（封面 48dp / 圆角 14dp）+ 一排大圆钮（56dp 圆、播放键米色底、28dp 图标、下带文字标签）：收藏 / 关于 / 添加（自己的歌单里多一个删除）。容器走 TokiSheetContainer。

## 分组列表（Gboard 式）

全应用列表的默认组织方式：一组一个容器、组内细分割线、组间留距；行是图标 + 标题 + 说明（说明最多 2 行）。三种现成实现，按场景选：

| 实现 | 形态 | 用在 |
|---|---|---|
| 设置分组卡（`TokiSettingsCard` + segmentedCorners，共享组件在 `Common.kt`；`SettingsScreen` 内的 SettingsSubCard 是同签名转发） | 分段圆角 28/4dp、组间 12dp、组内缝 4dp；卡内边距横 24 / 纵 8dp，横向边距默认 4dp（可传参） | 「我的」页各级页面、更多面板（底色传半透明、横向边距传 0） |
| TokiCardRow | 独立 20dp 圆角行、最小高 64dp、右侧 chevron | 资料库分区卡、本地页 |

分组标题用 SectionTitle（titleLarge，上 24 / 下 8dp）。

## 统一弹窗（TokiDialog）

出处：`TokiDialog.kt`（0.1.21 起全应用统一，旧 AlertDialog 样式不留孤岛）。

结构固定：左上图标（28dp）→ 标题（titleLarge）→ 副标题（可省，bodyMedium / onSurfaceVariant）→ 正文 → 右下双按钮（取消 / 确认，TextButton）。圆角 28dp、底 surfaceContainerHigh、内边距 24dp。破坏性确认时图标与确认文字走 error 色。单按钮、带输入的弹窗也走这个组件（正文区放输入控件）。

底部弹窗容器（TokiSheetContainer）：ModalBottomSheet、顶圆角 32dp、底 surfaceContainerLow、横向内边距 24dp、底部 28dp、行间距 4dp；搜索、更新提醒、歌曲操作等弹窗共用（「我的」页与更多面板不用它，走各自的玻璃结构）。容器色可传（如搜索页用 90% 不透明做半透明效果）。

## 按钮族

| 按钮 | 规格 |
|---|---|
| 玻璃圆钮（返回 chip / 侧边动作钮 / 顶栏图标钮） | 56dp 圆、图标 24dp、与标题同磨砂、pressScale 按压 |
| 小圆播放钮（SmallRoundPlayButton） | 40dp 圆、图标 24dp、surfaceContainer 底 |
| 大圆操作钮（SongActionButton） | 56dp 圆、图标 28dp、播放键米色底、下带 bodySmall 标签 |
| 封面圆钮（CircleArtButton） | 默认 48dp / 图标 24dp，底为封面自适应 14% 黑或白；无底形态传透明（播放器底部三钮） |
| 播放键 | 128×84dp、米色 `#F5E6D3` 底 + 深棕图标 40dp，圆角随播放态动画（42 / 28dp） |
| 分段 pill 组（TokiPillGroup） | 外容器 28dp 圆角 + surfaceContainer 底、内边距 4dp；pill 高 36dp 全圆；选中底 primaryContainer + onPrimaryContainer 字（titleMedium），指示器只动画 x 偏移（motionScheme 的 spatial spec），标签色走 effects spec 过渡 |
| 详情页播放组 | 播放 pill 高 56dp（inverseSurface 底）+ 48dp 模式钮（圆角 16dp） |

按压反馈两款（`Dest.kt`）：`pressScale`（默认缩到 0.92，pill 组用 0.96）与 `pressRebound`（默认 0.89，松手走 damping 0.45 / stiffness 500 的回弹弹簧；播放键、圆钮、MiniPlayer 播放钮用它）。

## 队列模式分段控件

出处：`PlayerScreen.kt` 队列视图顶部的 `QueueModeSegment`（0.1.23）。

播放队列顶部的模式切换是一个胶囊分段控件（取代旧的三个独立 pill）：容器高 56dp、全圆、底为 onCover 22% alpha、内边距 4dp，三段（顺序 / 随机 / 倒序）间距 4dp 等宽。选中段实底 onCover + 深色图标（取封面渐变下端色）；**未选中段只有一种样式**：透明底 + onCover 图标。映射由纯函数 `queueModeSegment` 决定，保证恰一段选中：Shuffle → 随机段、Reverse → 倒序段、Sequential / RepeatAll / RepeatOne → 顺序段；点按语义不变（点已激活段回顺序）。

## 来源图标与徽标

出处：`Common.kt` 的 `SourceBadge` / `SourceIcon`、`res/drawable/ic_source_*.xml`。

图标以 MingCute 线性套图（MIT）为主，YouTubeMusic 例外：

| 来源 | 资源 | 图形来源 |
|---|---|---|
| NeteaseMusic | `ic_source_netease` | MingCute netease-music-line |
| QQMusic | `ic_source_qq` | MingCute music-3-line |
| YouTubeMusic | `ic_source_youtube` | Simple Icons 的 youtubemusic glyph（用户 2026-11-27 指定） |
| Device | `ic_source_device` | MingCute device-line |

例外：`ic_local_music` 是 MDI 的 folder-music-outline（Apache 2.0），用于 SourceBadge / SourceIcon 的 LOCAL 形态（本地模式徽标），与本地页选项卡的 Device 图标不是同一个。

- SourceBadge：品牌色圆底 + 白色图标（图标边长 = 徽标的 0.6）；尺寸 20dp（行内）/ 28dp（歌单卡，内边距 6dp）。只在 ≥2 个在线源启用时显示（单源无歧义）；资料库单源分区内关闭。
- SourceIcon：裸图标无底，默认品牌色 tint；播放器更多面板头部传 onSurfaceVariant 与文字同色。
- 源切换钮（`SearchSourceButton`，`SearchScreen.kt`）：40dp 圆、图标 24dp；选中 = 品牌色底 + 白图标，未选中 = surfaceContainer 底 + 品牌色 50% alpha 图标。搜索页顶栏右侧与资料库分区顶栏右侧共用同一组件（间距 8dp，只渲染已启用的源，≥2 源启用时才出现）。
- 等级块 app 图标（`AppIconBadge`，`LibraryScreen.kt`）：28dp、白底、7dp 圆角 + `ic_launcher_foreground` 前景，与启动图标同构图；资料库等级块的 TokiMusic 行用它替代源图标（见《页面规范》）。
- 显示名固定为 `NeteaseMusic` / `QQMusic` / `YouTubeMusic` / `Device`（无空格）；「本地模式」「本地播放」等散文表述仍用中文。
