# 玻璃与材质

出处：`ui/theme/Glass.kt`（`TokiGlassParams` 与各玻璃 modifier）、`ui/player/PlayerScreen.kt`（更多面板）、`ui/settings/SettingsScreen.kt`（我的页）。

实现基于 Haze：窗口内采样（`HazeInput.Backdrop`）或内容源采样（`HazeInput.Sources`）。采样能力门槛：Android 12（API 31）以上（`TokiBlurCapability.canSampleInWindow`）。

## 玻璃三档

| 档 | 模糊半径 | 用在哪 |
|---|---|---|
| 普通档 `tokiGlass` / `tokiContentGlass` | 24dp | 标题 chip / 返回 chip 的默认磨砂 |
| 加强档 `tokiContentGlassStrong` | 32dp | 悬浮底栏（导航胶囊）、悬浮标题（strong 形态） |
| MiniPlayer 档 `tokiContentGlassMiniPlayer` | 85dp | MiniPlayer、播放器更多面板、「我的」页 |

共同参数：噪点 0.02（全档同值）；性能模式 Quality。

会改变尺寸的表面（导航胶囊、标题 chip）必须用内容源采样（`HazeInput.Sources`）——窗口采样在尺寸动画期间会黑边或掉模糊；固定尺寸表面可用窗口采样。

## tint（磨砂染色）

| 档 | 深色 | 浅色 |
|---|---|---|
| 普通档 | 白 20% | 暖深 `#2A2622` 16% + 白 46% |
| 加强档 | 白 30% | 同普通档浅色（暖深 16% + 白 46%） |
| MiniPlayer 档 | 无 tint（colorEffects 为空） | 同左 |

MiniPlayer 档自身不上色，底色由调用方以 `background` 形式把 veil 叠在模糊之上（veil 配方见《色彩》）。

## veil（玻璃之上的表面色罩）

| 表面 | veil |
|---|---|
| 标题 / 返回 chip（普通档） | surfaceContainer 24% |
| 标题 / 返回 chip（加强档）、导航胶囊 | surfaceContainer 45% |
| chip 描边 | 1dp、outlineVariant 45%（仅磨砂形态；采样不可用时无描边） |
| MiniPlayer | `miniPlayerGlassVeil`（动态，见《色彩》） |
| 更多面板 / 我的页 | `moreSheetGlassVeil` / `settingsSheetGlassVeil`，alpha 0.78 的主题色（两函数深色配方自 0.1.23 起不同，见《色彩》） |

## 渐进磨砂

`tokiGlassFade`：线性渐进模糊（强度 1 → 0 或 0 → 1），用于歌词页上下淡出带等需要「模糊渐渐消失」的边缘。参数与普通档相同（24dp、噪点 0.02、同 tint）。

## 什么时候用玻璃、什么时候用实色

- **玻璃是唯一 chrome 外观**（0.1.21 起）：原 TokiUI 的「玻璃关实色预设」（莫奈悬浮底栏 + 3dp primary 描边）已整套删除，应用内没有玻璃开关。
- 采样不可用（API < 31）时的兜底：Haze 样式自带 fallback 上色——深色黑 45% / 浅色白 72%；chip 退化为以 veil 透明度平涂的 surfaceContainer。文字不直接落在未受控的模糊上。
- **「我的」页的实色回退**：没有当前歌曲、取不到封面主题色时，不套玻璃，整页回退不透明 `surfaceContainerLow`（与该页 0.1.11–0.1.21 的实色形态一致）。有主题色时才走 85dp 玻璃 + 主题色 veil。
- 播放器页背景不是玻璃：是封面取色的实色渐变（见《色彩》）。

## 弹窗（对话框窗口）的采样边界

更多面板与「我的」页都是 `ModalBottomSheet`，位于独立的 Dialog 窗口内；它们的玻璃用 `HazeInput.Sources` 采样应用窗口内容，属跨窗口采样：

- 实际糊出效果需真机确认（0.1.22 / 0.2.0-beta1 均列为真机待验项）。
- 最差退化：采样不到时该样式 fallback 为全透明，但 veil 层仍在——面板退化为一块纯主题色实底（深浅随模式），不会黑屏、不会透光。
- 结构要求：sheet 容器色必须透明、自带拖柄关闭，玻璃挂在内容根 Box 上（先按 sheet 形状裁剪再套玻璃），内容里自绘同规格拖柄（32×4dp、onSurfaceVariant 40%），保证拖柄区也被玻璃盖住。
