# 歌词

出处：`data/lyric/YrcParser.kt`、`ui/AppViewModel.kt` 的 `loadLyrics`、`ui/player/LyricsScreen.kt`、`player/FloatingLyrics.kt`。

## 数据优先级

- 网易云：**YRC（逐字）优先** → YRC 解析不出行时对同一文本走 LRC 解析 → 只有 LRC 时用 LRC（行级）。QQ 音乐只有 LRC（行级），走同一套行级扫过。
- 本地文件歌：本地歌词优先（文件内嵌歌词 / `.lrc` 旁文件）；其次按登记的源身份在线回落——本地模式下不回落；源已关闭的歌不拉在线歌词。
- 翻译（tlyric）与罗马音（romalrc）按时间戳就近贴行：与原词行时间差 ≤ 500ms 才贴，贴不上就不显示，不编造。罗马音来自接口的 romalrc 字段，不是 YRC 自带。
- 词时长封顶（`effectiveWordDurationMs`）：YRC 词条的 durationMs 常含尾部静默，非行尾词取 min(自带时长，到下一词开始的间隔)，行尾词取 min(自带时长，行结束 − 词开始)；否则扫过会在行间空隙里慢爬。

## 逐字扫过（逐字高亮）

- 固定开启（设置 > 歌词的「逐字高亮」开关，播放页话筒钮已删）；关时当前行整行实色。
- 画法：双层同排版——底层整行 45% 透明，顶层实色用横向渐变 Brush 做扫过遮罩（实色到边界、末端 2dp 渐变到透明），边界随时间轴连续流动，不按字符取整硬切。
- 进度口径（像素口径）：每字进度由该字自己的时间窗驱动，段进度 = Σ（字进度 × 字像素宽）/ 段总宽，边界落在正在唱的字内部的正确比例处；无量测时退字数口径；LRC 行无逐字数据，走行级进度回退。
- 折行按视觉行分段：每段独立量宽、独立算进度、独立画双层；渐变宽用文本实测宽（不是容器宽），短行不会提前「扫完」。
- 时序偏移：逐字时序滑杆 ±500ms、50ms 步进（更多面板与设置同源），正值延后、负值提前。

## 行的呈现

排版数值见《排版与字体》。行为：

- 当前行判定：`activeLineIndex` = 最后一个 startMs ≤ 当前位置的行；还没唱到第一行时为 −1。
- **焦点行规则**：距离以焦点行为准（`lyricFocusIndex`）——active 为 −1 时焦点落到第 0 行，首行距离 0、恒清晰；当前行恒清晰。（旧实现把首行算成距离 1 糊掉，是 0.1.22 修的回归。）
- 点歌词行 = 跳到该行行首（行级跳转）；可点区只有文本实宽 + 8dp，右侧空白透传给父级手势。

## 距离模糊与位置淡化

两套模糊取大值施加（`LyricLineRow`）：

| 套 | 规则 |
|---|---|
| 距离模糊（`lyricDistanceBlurPx`） | 以焦点行为中心，每远一行 +3.5px、封顶 14px；焦点行 0 |
| 位置淡化 | 行中心进入上下渐隐带才生效：顶带 64dp、底带 96dp（下半段背景更暗、白字对比更高，故底带加宽让观感对称）；带内模糊量化 0→8px、alpha 最低 0.18 |

- 距离模糊随焦点移动用 300ms tween 过渡。
- 歌词区上下另有与封面渐变同色的淡出层（64 / 96dp）与渐进磨砂层（`tokiGlassFade`，采样可用时才画）。

## 手动翻看

- 手指拖动即进入翻看态（`userBrowsing`，只认手指拖动、程序滚动不触发）：自动跟随暂停，**距离模糊整体关**，位置淡化的模糊分量在实际滚动中也暂停（只保留 alpha 淡化），停稳后位置模糊恢复。
- 翻看态右下角出「回到当前行」圆钮（48dp、图标按当前行在上方 / 下方指方向），点它恢复跟随并滚回去。
- 跟随态的滚动方式见《动效》（视口内平滑滚动、视口外直接定位、锚点 20%）。

## 悬浮歌词

同一当前行数据（`LiveLyricLine`，与实时歌词通知共用）驱动的纯文字悬浮窗：形态、穿透与设置见《页面规范》的「悬浮歌词」节。
