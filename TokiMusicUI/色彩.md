# 色彩

出处：`ui/theme/TokiMusicColors.kt`、`ui/theme/Color.kt`、`ui/theme/CoverColors.kt`、`ui/components/Common.kt`（来源品牌色）。

## 总则

- TokiMusic 用自有固定色板，不用 TokiUI 种子色、不做动态取色。
- **深色为默认**；浅色模式于 0.1.21 加入（设置 → 个性化切换），与深色逐角色成对。
- 页面底色：深色纯黑 `#000000`、浅色纯白 `#FFFFFF`（`tokiPageColor()`）。所有「淡出到页面底」的渐变终点都从它取，不写死黑色。

## 封面取色与播放器主题色

出处：`CoverColors.kt` 的 `coverGradientFromPixels` / `extractCoverColors` / `CoverColors`。

- 取色：封面缩到 48px，取不透明像素（alpha ≥ 0x10）的平均色。
- 无彩回退：饱和度过低（max−min < 0.05）或过暗（max < 0.03）→ 暖棕渐变 `#5A2A12 → #2E1A0C`；取图失败同样回退。
- 归一化：最亮通道缩放系数 `0.45 / max`（钳制 0.5–3.0），保证白字对比；下端 = 上端 × 0.45 压暗。
- 产物 `CoverColors(top, bottom)`：播放器背景、MiniPlayer 进度线、详情页整页渐变、面板 veil 都从它派生。换歌时先回退暖棕，取色完成再切。
- **渐变中点色**：`lerp(top, bottom, 0.5)` 是「播放器主题色」的取法（更多面板 / 我的页 veil 的基准，见下）。
- 封面上的文字色：按渐变色相对亮度（WCAG 公式）二值定——亮度 > 0.35 用墨色 `#1C1C1E`，否则白色；次级文字为同色 70% alpha。元素不在顶部时按其高度处的渐变色定（`onCoverTextAt(fraction)`，判据同为 0.35）。
- 播放胶囊底色：亮封面 → `lerp(top, 黑, 0.65)` + 白图标；暗封面 → `lerp(top, 白, 0.75)` + 黑图标。
- 封面上的半透明按钮底：黑或白、alpha 0.14（按封面亮度二选一，`onCoverButtonBg()`）。

## veil 派生（玻璃底色）

| 函数 | 配方 |
|---|---|
| `miniPlayerGlassVeil(top, bottom, lightMode)` | 以封面渐变两端平均亮度 L 为信号：L ≤ 0.04 → 白色、alpha 0.25；L ≥ 0.65 → `#2C2C2E`、alpha 0.35；之间线性插值。浅色模式先把 L 抬到 ≥ 0.85（身后是白页，veil 必须落在深灰端） |
| `moreSheetGlassVeil(top, bottom, lightMode)` | 基准 = 渐变中点色；深色模式向黑压深 45%、浅色模式向白提亮 62%；alpha 同取 **0.78** |
| `settingsSheetGlassVeil(coverColors, lightMode)` | 与 `moreSheetGlassVeil` 同配方；无当前歌曲（coverColors 为 null）时返回 null，调用方回退实色（见《玻璃与材质》） |

## 来源品牌色

出处：`Common.kt` 的 `sourceBadgeBackground`；本地页选项卡（`LibraryScreen.kt` 的 `LocalBucketImportRow`）复用同一组色作线性图标 tint。

| 来源 | 显示名 | 品牌色 |
|---|---|---|
| NeteaseMusic | NeteaseMusic | `#FF5757` |
| QQMusic | QQMusic | `#879101` |
| Device（本地） | Device | `#A9A8D8` |

用法分工：徽标（SourceBadge）以品牌色为底、白色图标；裸图标（SourceIcon）默认以品牌色 tint，调用方可覆盖（播放器更多面板头部要求与文字同色，传 `onSurfaceVariant`，见《页面规范》）。
