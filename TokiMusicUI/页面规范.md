# 页面规范

出处：各页面源码；结构总览以 `ui/TokiMusicApp.kt` 的导航装配为准。

## 通用

- 一级页（主页 / 资料库）共用悬浮标题头 + 悬浮底栏（见《组件》）；二级页（详情、播放器）打开时应用 chrome 隐藏。
- 列表过冲走平台默认（见《动效》）；分组列表是默认组织方式（见《组件》）。

## 主页（Home）

出处：`ui/home/HomeScreen.kt`。

- 分区顺序：四大推荐块（可重排区）→ 最近播放 → 推荐歌单 → 推荐新歌 → 回顾 → 音乐记忆。
- 四大推荐块：每日推荐 / 私人雷达（QQ 源为 Daily 30 / For You）排成两列网格（间距 16dp），**长按拖动可互换位置**（手感见《动效》）；顺序持久化在 SettingsStore（`homeBlockOrder`），隐藏的块不渲染、存储顺序对可见块生效。其他分区不参与重排。
- 推荐块封面下半的主题色淡化：有封面取色时卡片渐变在 0.5 处之前全透明、底部收于该卡自己的 `coverBottomFadeColor`（见《色彩》），压住封面让底部标题 / 副标题读得清；无封面色时回退原中性黑 scrim（渐变档位随玻璃淡出层开关取 0.18/0.32 或 0.55/0.8）。
- 最近播放：读**本地播放记录**（PlayEventLog 去重取最近，见下「资料库」），不要求登录任何源。
- 推荐歌单：横向 2 行网格（高 424dp），多源同网格、卡带源徽标。推荐新歌：单源 3 行（每块高 220dp），按源分块（NeteaseMusic / QQMusic；YouTubeMusic 没有主页推荐流，不出现）。
- 音乐记忆：「10'26 音乐记忆」歌单（2026 年 10 月回顾，作者显示 TokiMusic，生成机制同回顾——PlayEventLog 月度聚合，无 ≥10 首门槛）；有数据为可点卡（第一首封面 +「N 首 · TokiMusic」），无数据为不可点空态卡「暂无播放记录」，不编造。
- 悬浮标题随滚动在「主页 / 推荐歌单 / 推荐新歌」间切换。
- 顶栏右侧头像进「我的」；搜索页与资料库分区的源切换在顶栏右侧（见《组件》的 SearchSourceButton）。
- 算法推荐口径：「我的 > 通用」的算法推荐开关默认开，但当前**置灰不可用**（文字 alpha 0.38、Switch 禁用，整行点击弹 Toast「算法推荐暂不可用」）。口味训练在本地持续进行：常听（PlayEventLog）+ 搜索词 / 歌手浏览信号（同一对象 ≥2 次才计入，单次不算），画像只存本机、参与推荐重排；主页没有独立的「算法推荐」分区。

## 资料库（Library）与本地页

出处：`ui/library/LibraryScreen.kt`。

- 分区：收藏 / 歌单 / 歌手 / 专辑 / 歌曲 / 本地。顶栏右侧是头像（进「我的」），与主页同落点。
- **分区源切换**（0.1.23）：收藏 / 歌单 / 歌手 / 专辑四个分区改为单源展示，顶栏右侧出现与搜索页同款的源切换钮行（SearchSourceButton，≥2 个在线源启用时才出现，规则见《组件》）；默认 NeteaseMusic，记住的源被关时钳到第一个开启的在线源。分区内容按所选源取数，YouTubeMusic 无账号资料库、四分区均为标准空态（不编造、不隐藏源）；分区内不再显示源徽标。资料库主页卡片的计数 / 副标题仍用合并列表。
- 「歌曲」分区 = 最近播放：只读**本地播放记录**（PlayEventLog 倒序去重、保留最近一次），不读任何源的云端记录、不要求登录；主页「最近播放」行与此处共用同一份计算。副文案恒为「X 首最近播放」。
- 分区照常展示，不因关源或本地模式隐藏；门控只落在播放上：关源且无本地文件的歌整行置灰、标「本地模式暂不可用」或「源已关闭暂不可用」、不可点播。
- 等级块（资料库统计对）：TokiMusic 行的等级值前置 app 图标（AppIconBadge，见《组件》），并显示本级进度条 + 「今日 X/135 分 · 距 Lv.N+1 还差 M 分」（满级显示「已满级 · 今日 X/135 分」）；整块可点，进等级详情页（见下节）。
- 听歌统计页（日 / 月 / 年三档）有「常听歌曲」区：当前区间播放次数 top 5、尾标「N 次」，空态「暂无播放记录」。数据口径：日级歌曲数据只存在于原始事件（本月内），跨月只有月度聚合——函数按「原始事件 + 整月落入区间的月聚合」合并，是真实口径不是缺陷。
- 本地页（分区「本地」的二级页）：
  - 页首简介段落与「导入本地歌曲」（一次扫三桶）行已于 0.1.23 删除；导入能力保留在每个桶自己的选项卡（点卡扫描 + 目录授权行）。
  - 选项卡：来源线性图标（品牌色 tint）+ 桶名 + 「已导入 N 首 · 点按扫描导入」，与卡片行同布局（横向 24dp、圆角 20dp、最小高 64dp）。
  - 已导入歌曲按歌单格式展示：NeteaseMusic（创建者「云音乐」）、QQMusic（创建者「企鹅音乐」）两歌单常显（0 首也显示）；Device 歌单只在非空时出现，创建者是用户的显示名（取不到时为 User）。
  - 「已下载歌单」分区（0.1.23）：歌单下载（见《详情页》）的成品在此按歌单格式镜像列出，点开是本地曲目、可离线 / 本地模式播放。
  - 歌曲的封面与歌词优先读文件内嵌信息（ID3 / FLAC 标签、`.lrc` 旁文件、MediaStore 封面）；有可靠源身份的歌可在线回落取封面 / 歌词，本地模式下不回落。

## 等级详情页

出处：`ui/library/LevelDetailScreen.kt`、`player/MusicLevel.kt`（0.1.23）。

- 入口：资料库等级块点击进入（二级页，返回回资料库一级）。
- 结构：标题行「音乐等级」（headlineMedium）+ 其正后方 beta 小徽章（圆角 6dp、surfaceContainerHigh 底、labelSmall、onSurfaceVariant 字）→ 大字号当前等级（displayMedium，「Lv.N」，满级为「Lv.25 · 满级」）→ 本级进度条 → 「达成条件」区。
- 进度条：高 28dp、圆角 14dp，轨道 surfaceContainerHighest、填充 primary（填充 = 本级下限 → 下一级门槛的进度）；三标注：当前总积分压在条上居中（surface 实底 chip、圆角 8dp、labelLarge），条下左 = 本级下限累计值，条下右 = 下一级门槛累计值（满级显示「满级」）。
- 等级规则（纯函数 `MusicLevel`，数字不许在 UI 另算）：上限 25 级；累计门槛 cumulative(L) = 60 × L²（Lv1 起点 0、Lv2 = 240、Lv25 = 37,500）；积分来源目前只有听歌——听满 1 分钟 +1 分、整首听完（播放达到 90%）+2 分/首，两者共用每日上限 **135 分**。
- 达成条件区：先一行「今日总积分 X / 135 分（每日上限）」，再逐行列积分来源（标题 + 说明 + 今日进度文案 + 6dp 小进度条）；列表式实现，将来新增来源往 `levelEarningRows` 加行。

## 播放器（Player）

出处：`ui/player/PlayerScreen.kt`。

- 形态：圆角面板（顶圆角 32dp、顶部留 28dp），外层满屏先铺同取色渐变盖住条带；背景是封面取色渐变、不是模糊封面。点空白区域返回（封面 / 歌词区与控制区有点击屏蔽）。
- 上半区三视图：封面 / 歌词 / 队列，左右划只在封面 ↔ 歌词间切换（阈值 60dp），队列由底部钮进出。封面圆角随视图动画：大封面 20dp ↔ 歌词视图 12dp。
- 头部（封面视图）：歌名（headlineSmall）+ 歌手（titleMedium）两行，右侧喜欢 / 更多两个封面圆钮（48dp）。歌名恒显示歌名（不被实时歌词替换）。
- 控制区：进度滑杆（拇指 4×28dp 圆角条，颜色随封面取色）+ 时间行；上一首 72dp 圆钮 + 播放键 + 下一首 72dp 圆钮；底部三钮（歌词 / 声音 / 队列）只有图标、无底。
- 沉浸式歌词：歌词视图双击进，隐藏整个控制区只留歌词；切歌或切回封面复位。
- 更多面板：见《组件》。

## 我的（原「账户与设置」）

出处：`ui/settings/SettingsScreen.kt` 的 `SettingsSheet`（0.2.0-beta1 改名与换底）。

- 形态：底部弹窗（顶圆角 28dp、全高 0.88、打开即全展开），纯文字标题（headlineMedium Bold）+ 36dp 纯色圆形关闭钮；子页在弹窗内切换（子页时关闭钮变返回）。
- 底色：有当前歌曲时 = 主题色玻璃（85dp 玻璃 + `settingsSheetGlassVeil`；深色配方与更多面板不同，见《色彩》）；无当前歌曲回退不透明 surfaceContainerLow。内容区上下 24dp 淡出色跟随实际底色，且**上下都按滚动门控**：顶部淡出只在列表已离开顶部（canScrollBackward）时画，底部淡出只在一级页列表还能向下滚（canScrollForward）时画——内容不满一屏时不画底带（0.1.23 修：无条件绘制会在玻璃底上压出一条假横条）。
- 一级页结构：头像卡 + 三源账号行（NeteaseMusic / QQMusic 行内含登录态与退出；YouTubeMusic 行只有启用开关、账号文案「无需登录」）+ 分区入口（通用 / 存储 / 个性化 / 音频 / 歌词 / 成就 / Toki 账号，入口行是 28dp 分段圆角卡、高 64dp）。
- 子页要点：
  - 通用下方是「存储」：显示真实文件占用（总量、可清理缓存、三桶 netease / qqmusic / download 占用；归不了类的本地歌计入 download 桶）。
  - 通用页的算法推荐开关置灰不可用（见主页节的算法口径）。
  - 个性化只有减少动效与浅色模式（外观固定玻璃，没有玻璃开关、没有实色预设）。
  - 歌词：翻译 / 罗马音 / 逐字高亮开关 + 悬浮歌词设置（见下节与《歌词》）。
  - 成就：成就卡可点击，弹 TokiDialog 展示详情（名称 / 说明 / 进度 / 解锁状态）。
  - Toki 账号（0.1.23，`ui/settings/TokiAccountSection.kt`）：Google 绑定卡（未绑定 = 「绑定 Google」钮；已绑定 = 头像 + 名 + 邮箱 + 解绑，解绑走 TokiDialog 确认）+ Drive 同步卡（授权后显示同步状态、上次同步时间、「立即同步」钮与自动同步开关）+ 数据存放说明。同步目标是**用户自己** Drive 的 appDataFolder（文件 `tokimusic-sync.json`，内容含设置 / 等级 / 口味画像 / 本地歌单结构 / 三源喜欢身份，明确排除一切登录凭据）。状态机要完整：OAuth 未配置时显示未配置态、Play 服务 / 登录不可用时显示不可用原因，两者都不许崩溃、也不影响应用其他功能；OAuth 客户端 ID 只有 build.gradle.kts 的 `GOOGLE_WEB_CLIENT_ID` 一个配置点。
- 开关源 / 退出登录要二次确认（统一弹窗）。

## 详情页（歌单 / 歌手 / 专辑）

出处：`ui/components/DetailScaffold.kt`、`HeaderScroll.kt`、`ui/albums/AlbumDetailScreen.kt`。

- 歌单与歌手共用 DetailScaffold：整页三段竖直渐变（0 → top、0.5 → bottom、1 → gradientBottom）；渐变末端色按页传（歌单用封面底色、歌手用纯黑、专辑用页面底色）。专辑页自有头部，手法相同。
- 折叠封面是列表第 0 项、随列表滑走：歌单 / 歌手占视口 1/3，专辑占 1/4（完整显示）。
- **封面下缘淡出**：终点色必须用 `detailGradientColorAt(top, bottom, gradientBottom, 封面底边比例)` 取整页渐变在该高度的真实颜色（纯函数，三段分段插值）；淡出集中在封面下部——渐变 stops 为 0 与 0.55 全透明、1.0 到终点色（即下部 45% 才淡）。终点色传错或全程线性淡出都会在封面与内容之间留硬分割线（0.1.22 修过的回归，不许重犯）。
- 标题块在封面下方（横向 24dp、纵向 16dp）；标题取色按其高度处的渐变色定（`onCoverTextAt`）。标题行完全滑出后，外层悬浮标题淡入。
- 歌曲行走分段圆角（20/8dp），行底色统一 `onCoverButtonBg()`。
- 歌单下载（0.1.23）：在线源歌单（NeteaseMusic / QQMusic / YouTubeMusic）的标题块统计行下有下载胶囊钮（底色取封面自适应色），状态机四态：未下载「下载歌单」/ 下载中「下载中 x/y」+ 转圈 / 已下载「已下载 N 首」/ 部分「已下载 a/b 首 · 继续下载」。整单逐首走该源自己的 songUrl 路由落本地（单首失败不中断整单），成品在本地页「已下载歌单」镜像（见资料库节）；门控与播放同口径（本地模式 / 源关闭拦截、QQ 需登录）。

## 悬浮歌词

出处：`player/FloatingLyrics.kt`、设置 > 歌词的 `FloatingLyricsSettingsCard`。

- 形态：无背景、无边框的纯文字悬浮窗（`TYPE_APPLICATION_OVERLAY`），只显示当前歌词行一行（单行、超长省略），锚在屏幕顶部区域。
- **点击全穿透**：`FLAG_NOT_FOCUSABLE | FLAG_NOT_TOUCHABLE`，不可选中、不可拖动，绝不拦截底下应用的操作；本体没有任何交互入口。
- 全部设置只在设置 > 歌词：开关（开时先走悬浮窗权限授权流）、颜色（白 / 黑两档）、字号（滑杆 12–28sp，默认 16sp）、位置（在设置内预览框里双轴拖动：上下 = 顶部比例 0–0.85，左右 = 水平比例 −1..1、偏移 = 比例 × 屏宽 / 2）。
- 视觉分组：开启时开关卡（First）与控制卡（Last）用 segmentedCorners 连成一个分组板块；关闭时只剩开关卡（Single）。
- 显示条件：开关开 + 有权限 + 有当前歌曲 + 有当前行，缺一即移除窗口不留残留；暂停时保留上一行。

## 更新呈现

出处：`update/UpdateDialog.kt`、`update/UpdateChecker.kt`。

- 更新提醒是底部弹窗（TokiSheetContainer）：标题 + 「当前版本 → 新版本」+ 说明全文（限高 280dp 可滚动区域，不截断）+ 安装包大小 + 「立即更新」（56dp 全宽）/「稍后提醒」。
- **测试版本标注**（0.2.0-beta1 起）：版本号含 beta / alpha 后缀（新格式 x.x.x-betax / x.x.x-alphax）时，标题改「发现测试版本 {版本}」、副行改「→ 测试版本」；正式版维持「发现新版本」。判定函数 `isTestVersion`：取 `-` 后预发布段以 beta / alpha 开头为真，旧 `-bN` 后缀不算。
- 测试版本走正常更新通道：检查不排除、不隐藏、无独立渠道，发布页正常发布（不勾预发布）。
