# 页面规范

出处：各页面源码；结构总览以 `ui/TokiMusicApp.kt` 的导航装配为准。

## 通用

- 一级页（主页 / 资料库）共用悬浮标题头 + 悬浮底栏（见《组件》）；二级页（详情、播放器）打开时应用 chrome 隐藏。
- 列表回弹全页统一（见《动效》）；分组列表是默认组织方式（见《组件》）。

## 主页（Home）

出处：`ui/home/HomeScreen.kt`。

- 分区顺序：每日推荐 / 私人雷达双卡（QQ 源为 Daily 30 / For You）→ 最近播放 → 推荐歌单（横向 3 行网格，双源同网格、卡带源徽标）→ 推荐新歌（按源分行）。
- 悬浮标题随滚动在「主页 / 推荐歌单 / 推荐新歌」间切换。
- 顶栏左侧：双源都启用时有源切换下拉入口（标题组最左、与标题 chip 同 12dp 间距）；右侧头像进「我的」。
- 算法推荐口径：算法开关关（默认）= 当前源的默认推荐；开 = 按口味数据重排。主页没有独立的「算法推荐」分区。

## 资料库（Library）与本地页

出处：`ui/library/LibraryScreen.kt`。

- 分区：收藏 / 歌单 / 歌手 / 专辑 / 歌曲 / 本地。顶栏右侧是头像（进「我的」），与主页同落点。
- 分区照常全量展示，不因关源或本地模式隐藏；门控只落在播放上：关源且无本地文件的歌整行置灰、标「本地模式暂不可用」或「源已关闭暂不可用」、不可点播。
- 本地页（分区「本地」的二级页）：
  - 页首是导入按钮：点一次扫三桶（NeteaseMusic / QQMusic / Device）；每个桶也有一张选项卡可单独扫。
  - 选项卡：来源线性图标（MingCute，品牌色 tint）+ 桶名 + 「已导入 N 首 · 点按扫描导入」，与卡片行同布局（横向 24dp、圆角 20dp、最小高 64dp）。
  - 已导入歌曲按歌单格式展示：NeteaseMusic（创建者「云音乐」）、QQMusic（创建者「企鹅音乐」）两歌单常显（0 首也显示）；Device 歌单只在非空时出现，创建者是用户的显示名（取不到时为 User）。
  - 歌曲的封面与歌词优先读文件内嵌信息（ID3 / FLAC 标签、`.lrc` 旁文件、MediaStore 封面）；有可靠源身份的歌可在线回落取封面 / 歌词，本地模式下不回落。

## 播放器（Player）

出处：`ui/player/PlayerScreen.kt`。

- 形态：圆角面板（顶圆角 32dp、顶部留 28dp），外层满屏先铺同取色渐变盖住条带；背景是封面取色渐变、不是模糊封面。点空白区域返回（封面 / 歌词区与控制区有点击屏蔽）。
- 上半区三视图：封面 / 歌词 / 队列，左右划只在封面 ↔ 歌词间切换（阈值 60dp），队列由底部钮进出。封面圆角随视图动画：大封面 20dp ↔ 歌词视图 12dp。
- 头部（封面视图）：歌名（headlineSmall）+ 歌手（titleMedium）两行，右侧喜欢 / 更多两个封面圆钮（48dp）。歌名恒显示歌名（不被实时歌词替换）。
- 控制区：进度滑杆（拇指 4×28dp 圆角条，颜色随封面取色）+ 时间行；上一首 72dp 圆钮 + 播放键 + 下一首 72dp 圆钮；底部三钮（歌词 / 声音 / 队列）只有图标、无底。
- 沉浸式歌词：歌词视图双击进，隐藏整个控制区只留歌词；切歌或切回封面复位。
- 更多面板：见《组件》。

## 我的（原「账户与设置」）

出处：`ui/settings/SettingsScreen.kt` 的 `SettingsSheet`（0.2.0-beta1 改名与换底）。

- 形态：底部弹窗（顶圆角 28dp、全高 0.88、打开即全展开），纯文字标题（headlineMedium Bold）+ 36dp 纯色圆形关闭钮；子页在弹窗内切换（子页时关闭钮变返回）。
- 底色：有当前歌曲时 = 主题色玻璃（85dp 玻璃 + `settingsSheetGlassVeil`，与更多面板同配方同家族）；无当前歌曲回退不透明 surfaceContainerLow。内容区上下 24dp 淡出色跟随实际底色；顶部淡出只在列表已离开顶部时画。
- 一级页结构：头像卡 + 两源账号行（各源 logo 行内含登录态与退出）+ 分区入口（通用 / 存储 / 个性化 / 音频 / 歌词 / 成就，入口行是 28dp 分段圆角卡、高 64dp）。
- 子页要点：
  - 通用下方是「存储」：显示真实文件占用（总量、可清理缓存、三桶 netease / qqmusic / download 占用；归不了类的本地歌计入 download 桶）。
  - 个性化只有减少动效与浅色模式（外观固定玻璃，没有玻璃开关、没有实色预设）。
  - 歌词：翻译 / 罗马音 / 逐字高亮开关 + 悬浮歌词设置（见下节与《歌词》）。
- 开关源 / 退出登录要二次确认（统一弹窗）。

## 详情页（歌单 / 歌手 / 专辑）

出处：`ui/components/DetailScaffold.kt`、`HeaderScroll.kt`、`ui/albums/AlbumDetailScreen.kt`。

- 歌单与歌手共用 DetailScaffold：整页三段竖直渐变（0 → top、0.5 → bottom、1 → gradientBottom）；渐变末端色按页传（歌单用封面底色、歌手用纯黑、专辑用页面底色）。专辑页自有头部，手法相同。
- 折叠封面是列表第 0 项、随列表滑走：歌单 / 歌手占视口 1/3，专辑占 1/4（完整显示）。
- **封面下缘淡出**：终点色必须用 `detailGradientColorAt(top, bottom, gradientBottom, 封面底边比例)` 取整页渐变在该高度的真实颜色（纯函数，三段分段插值）；淡出集中在封面下部——渐变 stops 为 0 与 0.55 全透明、1.0 到终点色（即下部 45% 才淡）。终点色传错或全程线性淡出都会在封面与内容之间留硬分割线（0.1.22 修过的回归，不许重犯）。
- 标题块在封面下方（横向 24dp、纵向 16dp）；标题取色按其高度处的渐变色定（`onCoverTextAt`）。标题行完全滑出后，外层悬浮标题淡入。
- 歌曲行走分段圆角（20/8dp），行底色统一 `onCoverButtonBg()`。

## 悬浮歌词

出处：`player/FloatingLyrics.kt`、设置 > 歌词的 `FloatingLyricsSettingsCard`。

- 形态：无背景、无边框的纯文字悬浮窗（`TYPE_APPLICATION_OVERLAY`），只显示当前歌词行一行（单行、超长省略），锚在屏幕顶部区域。
- **点击全穿透**：`FLAG_NOT_FOCUSABLE | FLAG_NOT_TOUCHABLE`，不可选中、不可拖动，绝不拦截底下应用的操作；本体没有任何交互入口。
- 全部设置只在设置 > 歌词：开关（开时先走悬浮窗权限授权流）、颜色（白 / 黑两档）、字号（滑杆 12–28sp，默认 16sp）、位置（在设置内预览框里双轴拖动：上下 = 顶部比例 0–0.85，左右 = 水平比例 −1..1、偏移 = 比例 × 屏宽 / 2）。
- 视觉分组：开启时开关卡（First）与控制卡（Last）用 segmentedCorners 连成一个分组板块；关闭时只剩开关卡（Single）。
- 显示条件：开关开 + 有权限 + 有当前歌曲 + 有当前行，缺一即移除窗口不留残留；暂停时保留上一行。

## 更新呈现

出处：`update/UpdateDialog.kt`、`update/UpdateChecker.kt`。

- 更新提醒是底部弹窗（TokiSheetContainer）：标题 + 「当前版本 → 新版本」+ 说明全文（限高 280dp 可滚动区域，不截断）+ 安装包大小 + 「立即更新」（56dp 全宽）/「稍后提醒」。
- **测试版本标注**（0.2.0-beta1 起）：版本号含 beta / alpha 后缀（新格式 x.x.x-betax / x.x.x-alphax）时，标题改「发现测试版本 {版本}」、副行改「→ 测试版本」；正式版维持「发现新版本」。判定函数 `isTestVersion`：取 `-` 后预发布段以 beta / alpha 开头为真，旧 `-bN` 后缀不算。
- 测试版本走正常更新通道：检查不排除、不隐藏、无独立渠道，发布页正常发布（不勾预发布）。
