# TokiMusicUI 设计规范

本目录是 TokiMusic 自己的设计规范：把应用当前实际在用的色彩、玻璃、字体、形状、组件、动效与页面规则从代码里提炼成文，方便后续开发对照。

- **适用版本**：TokiMusic Android 0.2.0-beta1（仓库 main `180e27a7`）起。
- **事实来源**：本目录所有数值都取自应用代码（主题文件、组件源码、纯函数），出处在各文件里标注到文件级。**代码是唯一事实来源**；本文与代码不一致时，以代码为准，并应回头修本文。
- **平台范围**：只覆盖 Android 端。iOS / Windows 未按本规范实现。

## 与 TokiUI 0.2.0-beta1 的关系

TokiMusic 在结构上沿用 TokiUI / MD3E 的大框架（统一标题头、悬浮底栏、分组列表、玻璃 chrome、语义间距 token 等），但在以下方面走自己的配方，**以本规范为准**：

| 方面 | TokiUI | TokiMusic（本规范） |
|---|---|---|
| 色板 | 种子色 `#6750A4` + 动态取色 | 自有固定色板（深色默认 + 成对浅色），不读种子色、不做动态取色。见《色彩》 |
| 字重 | 标题 Bold / 正文 Regular | **全应用 Bold**（用户 2026-11-21 定，含正文与标签）。见《排版与字体》 |
| 中文字体 | Source Han Sans（打包为 Noto Sans SC） | 苹方 SC Bold（静态文件）。见《排版与字体》 |
| 玻璃回退 | 玻璃关时有实色底栏预设（莫奈悬浮底栏 + 3dp 强调色描边） | 该预设已于 0.1.21 整套删除：玻璃是唯一 chrome 外观；实色只在采样不可用（系统版本不足）时作兜底。另有 TokiUI 没有的 MiniPlayer 85dp 专用玻璃档。见《玻璃与材质》 |
| 过冲效果 | 平台默认 | 自研回弹过冲（24dp 渐近、临界阻尼），全局一套参数。见《动效》 |
| 播放器主题色 | 无此概念 | 封面取色派生整套播放器 / 面板底色。见《色彩》 |

仍在沿用 TokiUI 的部分：

- 语义间距 token（`space`：xs 4 / sm 8 / md 12 / lg 16 / xl 24 / xxl 32），运行时经 `tokiSpace()` 读取——但只在标题头与少数位置用，多数间距在代码里是字面 dp。
- 形状阶梯的数值（4 / 8 / 12 / 16 / 28 / 全圆）与 MD3 默认 `Shapes()` 恰好一致；应用直接用 MD3 默认 `Shapes()`，不从 token 读形状。
- 快照：`android/tokiui/` 是 TokiUI 的只读快照（来源标签 v0.1.4、提交 `0edda32`）。注意快照内的 token 文件 `version` 字段仍写 `0.2.0-b1`——规范已于 2026-11-27 改名 0.2.0-beta1，快照尚未刷新；这属于文档与代码的已知不一致，以规范现名（0.2.0-beta1）为准。
